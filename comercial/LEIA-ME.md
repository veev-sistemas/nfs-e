# Material comercial VEEV NFS-e

## Vídeo para WhatsApp

Arquivo: `veev-nfse-whatsapp.mp4`. Duração: 63 segundos, vertical 720 × 1280, H.264. Tem textos explicativos e movimento suave, sem narração ou música. Pode ser enviado como vídeo pelo WhatsApp.

## Demonstração interativa

Abra `demonstracao-veev.html` no navegador com um duplo clique. Funciona sem internet e sem instalar o sistema. As imagens estão incluídas no próprio arquivo: você pode enviar somente esse HTML para outro computador.

Use Próximo/Anterior, os números das etapas ou as setas do teclado. Clique nas telas para ampliar. O botão Apresentação automática avança a cada nove segundos; clique novamente para pausar.

É um tour guiado das telas, não uma versão operacional do sistema. Os botões dentro das capturas são ilustrativos. Não realiza emissão, cancelamento ou consulta fiscal real.

## Roteiro de venda

O arquivo `roteiro-demonstracao.md` contém uma sugestão de fala e uma mensagem para acompanhar o vídeo no WhatsApp. O convite final é genérico, sem preços nem contato inventado.

Todas as capturas usam dados fictícios do modo de demonstração local. Nenhum cliente real, senha, certificado ou chave de API foi incluído.

## Regenerar

`gerar-material.py` usa Pillow e imageio-ffmpeg. A pasta `assets` contém as capturas originais do sistema. Execute o script com Python para recriar o HTML e o MP4.
